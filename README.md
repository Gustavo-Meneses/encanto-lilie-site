# ✨ Encanto Liliê - Site de Vendas

Este é o site oficial de catálogo da **Encanto Liliê**, desenvolvido com Python e Streamlit para exibir artesanatos personalizados de forma vibrante e intuitiva.

## 🚀 Como subir o site (Passo a Passo Web)

Como você está em uma máquina corporativa, siga estes passos 100% no navegador:

1.  **GitHub:**
    * Crie um novo repositório chamado `encanto-lilie-site`.
    * Crie um arquivo chamado `streamlit_app.py` e cole o código que te enviei.
    * Crie um arquivo chamado `requirements.txt` e escreva apenas: `streamlit` (isso avisa ao servidor que ele precisa instalar o Streamlit).

2.  **Streamlit Cloud:**
    * Acesse [share.streamlit.io](https://share.streamlit.io).
    * Conecte sua conta do GitHub.
    * Clique em **"Create app"** e selecione o seu repositório `encanto-lilie-site`.
    * Clique em **"Deploy!"**.

3.  **Imagens:**
    * Para usar as fotos reais do Instagram, você pode subir as fotos na pasta do GitHub e mudar o link no código de `https://placehold.co/...` para o nome do arquivo, ou usar links diretos de um hospedeiro de imagens.
